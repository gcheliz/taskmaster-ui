# TaskMaster UI Component Library

Welcome to the TaskMaster UI component library documentation! This comprehensive guide will help you understand, use, and contribute to our design system.

## 🎯 Overview

The TaskMaster UI component library is built with:

- **React 19** with TypeScript for type safety
- **Tailwind CSS v4** for utility-first styling
- **Storybook 9** for component documentation
- **Atomic Design** methodology for scalable architecture
- **Accessibility-first** approach following WCAG 2.1 guidelines

## 🚀 Getting Started

### Installation

```bash
# Install dependencies
pnpm install

# Start Storybook
pnpm run storybook

# Build for production
pnpm run build-storybook
```

### Basic Usage

```tsx
import { Button, Input, FormField } from '@/components/ui';

function MyComponent() {
  return (
    <div>
      <Button variant="primary" size="md">
        Click me
      </Button>
      
      <FormField
        label="Email"
        type="email"
        placeholder="Enter your email"
        required
      />
    </div>
  );
}
```
