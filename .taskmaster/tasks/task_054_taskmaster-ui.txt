## 2. Implement Advanced Drag-and-Drop with Visual Feedback and Keyboard Accessibility [done]
### Dependencies: 54.1
### Description: Enable users to move task cards between columns using both mouse-based drag-and-drop and full keyboard controls, providing clear visual feedback during the interaction.
### Details:
Integrate a drag-and-drop library (e.g., dnd-kit) to handle card movement. Implement visual feedback, such as a ghost element or placeholder, during the drag operation. Update the task's status and position in the local state upon a successful drop. Ensure full keyboard accessibility for these interactions (e.g., using Tab to focus, Spacebar to lift/drop, and Arrow Keys to move between columns).

## 3. Integrate Real-Time Collaboration via WebSockets [done]
### Dependencies: 54.2
### Description: Implement real-time synchronization to ensure that all changes made to the Kanban board are instantly reflected for all concurrently active users.
### Details:
Establish a WebSocket connection to the backend. When a user moves a task, an event containing the task ID and new status/column will be emitted to the server. The client will listen for broadcasted events from the server and update the UI dynamically to reflect changes made by other users without a page refresh.

The board view must dynamically update to show only the tasks that match the active search and filter criteria.
