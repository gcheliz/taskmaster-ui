# Task ID: 63
# Title: Page Implementation: Authentication System
# Status: done
# Dependencies: 57, 58, 60
# Priority: medium
# Description: Create a modern authentication interface with tabbed login/registration, social authentication (GitHub, Google), role-based registration, password strength indicators, terms of service agreements, and animated background effects with glassmorphism design.
# Details:
Implement the authentication page based on the provided HTML mockups, incorporating a tabbed interface and modern security features. The implementation will be broken down into several key areas:

1.  **UI & Component Structure:**
    *   Use atomic components from Task #58 to build the page.
    *   Create a main `AuthPage` organism containing a tab component to switch between 'Login' and 'Registration' forms.
    *   Implement the glassmorphism effect using CSS `backdrop-filter: blur()` and a semi-transparent background. The animated background can be achieved with a lightweight library like `particles.js` or custom CSS animations.

2.  **Form Handling & Validation:**
    *   Utilize a robust form management library like `React Hook Form` paired with `Zod` for schema-based validation to handle form state, validation, and submission efficiently.
    *   Implement real-time, client-side validation for fields like email format and password requirements.

3.  **Social Authentication (OAuth 2.0):**
    *   Integrate 'Login with Google' and 'Login with GitHub' buttons.
    *   On click, redirect the user to the respective provider's OAuth consent screen.
    *   Create a callback route in the application (e.g., `/auth/callback`) to handle the redirect from the provider, capture the authorization code, and send it to the backend API for token exchange and session creation.

4.  **Registration Features:**
    *   **Password Strength:** Integrate a library like `zxcvbn` to analyze password strength in real-time. Display feedback to the user via a multi-colored progress bar and textual hints (e.g., 'Weak', 'Good', 'Strong').
    *   **Role Selection:** Include a dropdown or radio button group in the registration form for users to select their role (e.g., 'Developer', 'Project Manager').
    *   **Terms of Service:** Add a mandatory checkbox with a link to the Terms of Service. The 'Register' button should remain disabled until this box is checked.

# Test Strategy:
1.  **Unit Tests (Jest/Vitest + React Testing Library):**
    *   Test the `AuthPage` tab component to ensure correct content is rendered on tab switch.
    *   Unit test form input components, mocking user input to verify validation logic (e.g., invalid email format, password mismatch) and error message display.
    *   Mock the `zxcvbn` library to test the `PasswordStrengthIndicator` component, asserting that it displays the correct visual state for different password inputs.
    *   Verify that the registration form's submit button is disabled/enabled based on the 'Terms of Service' checkbox state.

2.  **Integration Tests (using Mock Service Worker - MSW):**
    *   Mock the backend authentication API endpoints (`/login`, `/register`, `/oauth/callback`).
    *   Test the full user flow for both email/password login and registration, asserting that correct data is sent to the mock API and the UI reacts appropriately to success or error responses.
    *   Test the OAuth flow by mocking the window.location redirect and simulating the provider's callback with a dummy authorization code, ensuring the code is correctly sent to the backend.

3.  **End-to-End Tests (Cypress/Playwright):**
    *   Write a test script that simulates a new user registering via the form, including role selection and ToS agreement.
    *   Write a test script for a user logging in with valid and invalid credentials.
    *   Visually test the animated background and glassmorphism effects using visual regression testing to prevent unintended style changes.
    *   Verify the social login buttons redirect to the correct external URLs.
